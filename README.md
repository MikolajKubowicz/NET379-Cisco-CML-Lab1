# NET 379 - Cisco Modeling Labs

## Lab 1: CML Setup

This lab focused on installing and configuring Cisco Modeling Labs (CML),
running Cisco virtual routers and switches, connecting to devices using
MobaXterm, and exporting the completed lab configuration as YAML.

### Technologies Used
- Cisco Modeling Labs 2.9
- VMware Workstation Pro
- Cisco IOS
- MobaXterm
- YAML

### Lab Tasks
- Installed and configured CML
- Imported and launched a 5-node topology
- Connected to Cisco devices through the console
- Modified and saved router configuration
- Extracted running configurations
- Validated a 20-node CML topology
- Monitored CPU and memory utilization
